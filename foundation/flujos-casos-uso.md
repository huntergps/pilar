# Flujos y Casos de Uso

> Los flujos y casos de uso de cada módulo están documentados en el `module.md` de cada módulo. Este archivo documenta los actores del sistema base.

## Actores del Sistema

| Actor | Descripcion |
|-------|-------------|
| **Administrador** | Configura empresa, usuarios, roles, parámetros del sistema |
| **Operador** | Ejecuta operaciones del día a día según los módulos activos en su empresa |
| **Supervisor** | Aprueba, revisa y audita operaciones de otros usuarios |
| **Gerente** | Consulta reportes y dashboards consolidados |
| **Sistema Externo** | Plataforma externa que envía o recibe datos del ERP vía API |
